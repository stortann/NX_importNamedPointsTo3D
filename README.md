# NX_importNamedPointsTo3D
## Functionality
This journal imports and names points from a .txt file into an open 3D part. It will ask you to insert the full path to the .txt, and then create points according to that .txt file. Each point should be on the new line, in the format below:

| name1 | x1 | y1 | z1 |
| --- | --- | --- | --- |
| **name2** | **x2** | **y2** | **z2** |
| **...** | **...** | **...** | **...** |

Example:

| myPoint1 | -56.005 | 3.1 | -1 |
| --- | --- | --- | --- |
| **myPoint2** | **202.88** | **35.5** | **0** |
